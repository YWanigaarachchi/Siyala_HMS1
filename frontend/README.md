# Siyala HMS - Customer Web Frontend

This is the React frontend for the Siyala HMS Customer Web application. It allows guests to view hotels, make reservations, and manage their profiles.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

For more details on the project and branch context, please see the [root README](../README.md).
